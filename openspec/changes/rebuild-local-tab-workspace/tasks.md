# 实施任务

## 审阅摘要

- 实施目标：在现有技术栈上完成已确认的 Toby Mini 2.0 核心单机工作台，包括 Chrome 原生标签组。
- 依赖顺序：批准方案 → 数据模型和存储 → 浏览器读写与同步 → 工作台 → 拖拽搜索 → 综合验收。
- 完成定义：三份 specs 的场景通过，真实 Chrome 核心闭环通过，公开视觉基准核对完成且用户实物验收完成；不能仅以构建通过或静态预览认定完成。
- 最终验证集合：聚焦自动测试、`pnpm run compile`、`pnpm run build`、多窗口／组／重启／离线手工回归、视觉状态矩阵、OpenSpec 严格校验。
- 当前状态：用户已明确批准实施，公开配图检查完成；首版实现与自动验证完成；用户确认真实 Chrome 及 Toby 实物验收清单全部符合预期，唯一插件页面显示差异已修复并回归通过，详见 `validation.md`。

## 1. 方案与验收基准

- [x] 1.1 取得用户对 proposal、specs、design、tasks 的明确实施批准并记入 research — 验证：用户答复“批准，按方案开始实施”，之后进入业务代码开发。
- [x] 1.2 检查官方保存会话、原生组、搜索配图，整理与主图统一的视觉状态清单；保留实物对照项 — 验证：已目视检查五张公开图片并记录于 research V3–V7，设计补充保存弹窗、组列表和搜索浮层细节；用户已完成实物验收，差异及修复见 validation。

## 2. 本地领域与数据存储

- [x] 2.1 替换 `src/types/core.ts`，实现纯资料库模型和校验；收藏使用稳定本地 id，有序嵌套空间／集合／卡片 — 验证：级联删除、同集合重排、跨集合移动、合并、重复 URL 保留及非法输入测试通过。
- [x] 2.2 在 storage 模块建立独立版本化资料库并实现首次初始化、读库错误、损坏和未来版本处理 — 验证：只有不存在时初始化 Personal 空间；损坏数据和旧项目键不被覆盖。
- [x] 2.3 实现 background 单写入队列与类型化 mutation 协议，UI 不提交整库替换 — 验证：并发新增均保留，目标被删除时失败，前次失败不阻断后续写入。
- [x] 2.4 建立资料库读取／订阅客户端和 Zustand 状态，落实 loading/ready/error/pending — 验证：两个工作台修改后同步；写入失败无成功提示；消息超时不自动重复 mutation。

## 3. 浏览器目录与原生标签组

- [x] 3.1 扩展 windowCatalog 实时类型、查询与错误返回，读取窗口、标签、组、固定／激活状态 — 验证：多窗口顺序、组名颜色和未分组标签正确；所有插件页面不进入目录和保存列表。
- [x] 3.2 补齐 tabs/windows/tabGroups 事件，加入查询序号与后台 epoch，页面重新可见时刷新 — 验证：标题导航、跨窗口移动、组编辑和后台重启后同步，旧响应不能覆盖新目录。
- [x] 3.3 实现可测试的浏览器 adapter：聚焦、关闭、移动、编辑组、取消分组 — 验证：API 拒绝或对象消失产生明确错误并重新读取状态；取消分组不关闭标签。
- [x] 3.4 调整 Manifest，保留独立页面入口，移除不再需要的保活和示例 content script — 验证：权限仅用于设计中的 API；无新标签页覆盖、远程主机注入或定时保活；连续点击图标不会重复创建工作台。

## 4. 保存与恢复编排

- [x] 4.1 实现整窗、原生组、单标签的快照保存到新集合或已有集合 — 验证：窗口保存排除固定标签，组名颜色和顺序保持，空选择不创建集合，不按 URL 去重。
- [x] 4.2 实现保持／关闭选择及记住偏好，关闭源标签前等待写入并复查 URL／窗口／组 — 验证：写入失败零关闭；导航或移走的标签跳过；固定标签不被关闭；关闭部分失败不重复保存。
- [x] 4.3 实现单卡打开、集合普通恢复和原生组恢复 — 验证：目标窗口及顺序正确，组使用新 groupId 和保存颜色，原收藏保留；缺少组色的普通集合恢复为灰色组。
- [x] 4.4 实现恢复部分失败及分组失败反馈和针对性重试 — 验证：成功页面不被关闭或重复打开，失败阶段清晰，本地数据不变。

## 5. 三栏工作台与基本管理

- [x] 5.1 重建 App 和 home，移除本次替换后无用的账号／团队流程，落地浅色三栏基础布局 — 验证：首次打开直接使用；1440 × 900 和 1920 × 1080 可读；1280 × 720 关键操作不遮挡。
- [x] 5.2 实现空间导航、空间／集合 CRUD、计数和集合展开折叠 — 验证：空态、重命名、非空删除确认及取消、最后一个空间删除符合 specs，其他空间和浏览器不受影响。
- [x] 5.3 实现卡片标题／URL 编辑、打开、移除及本地 favicon 降级 — 验证：无效 URL 不覆盖旧值；相同 URL 的其他记录不被删除；离线缺图不阻断工作台。
- [x] 5.4 实现 Open Tabs 的窗口、原生组和标签 UI，以及保存／恢复／组编辑操作入口 — 验证：计数和浏览器状态一致，原生组颜色与折叠正确，错误／部分成功可区分。
- [x] 5.5 实现必要的保存、恢复偏好和全局操作反馈 — 验证：用户可以撤回“记住选择”，UI 不展示 Next、Tags、星标、主题等延期入口。

## 6. 搜索与拖拽

- [x] 6.1 实现 All/Spaces/Collections/Tabs/Open tabs 搜索和键盘入口 — 验证：大小写与 URL 查询、分类、无结果、结果打开与集合跳转行为符合 specs；输入法及文本输入不误触单键快捷键。
- [x] 6.2 实现卡片／集合排序、跨集合与跨空间移动、空集合落点及键盘替代入口 — 验证：源目标和顺序正确，Esc／无效 drop 不改数据，写入失败撤销预览。
- [x] 6.3 实现集合合并和间隙新建集合 — 验证：合并与排序目标可区分，来源顺序不变且不去重，命名或合并取消不修改资料。
- [x] 6.4 接通实时标签拖入收藏、收藏拖回窗口／组和实时标签跨窗口／组移动 — 验证：复用同一保存和 adapter 逻辑；实际 Chrome 状态吻合；部分失败重新同步而不伪造成功。
- [x] 6.5 完成长列表边缘自动滚动、拖拽落点反馈、focus 和弹窗 Esc 行为 — 验证：空集合、长页、多组和键盘操作都能完成目标动作；鼠标结束或 Esc 后无残留预览。
