## 审阅摘要

- 目标：离线迁移资料库及本机界面偏好。
- 结果：可下载完整备份，可选择追加或替换，默认追加。
- 边界：本产品 JSON 格式；无云端、第三方格式或实时标签操作。
- 验收：往返、重复值与排序、坏文件、失败和并发场景；实施细节见 design，待整体批准。

## ADDED Requirements

### Requirement: 完整备份

系统 SHALL 导出带可识别格式版本的 JSON 文件，包含全部空间、集合、卡片、行为偏好及本机界面偏好，并保留内容、顺序与原生组颜色。

#### Scenario: 离线导出并迁移

- **WHEN** 用户在离线状态导出当前资料库，并在另一环境导入备份
- **THEN** 空间、集合、卡片的文字、网址、顺序、组颜色与重复网址均可恢复，行为偏好和界面偏好可迁移

### Requirement: 两种导入方式

系统 SHALL 支持追加与替换导入，默认选择追加，在写入前展示内容数量及所选模式的影响，只有确认后执行导入。

#### Scenario: 追加备份

- **WHEN** 用户选择追加并确认
- **THEN** 现有内容保持不变，备份空间按原顺序追加，不按同名空间或重复网址去重

#### Scenario: 替换备份

- **WHEN** 用户选择替换并确认覆盖影响
- **THEN** 资料库内容及行为偏好被备份恢复，浏览器中的实时标签不受影响

#### Scenario: 取消预览

- **WHEN** 用户选择文件后取消导入
- **THEN** 资料库与界面偏好均不发生写入

### Requirement: 校验与失败保护

系统 MUST 校验备份身份、版本、结构和领域数据，在失败时保留现有资料库，且只在持久化成功后报告导入成功。

#### Scenario: 非法或未知版本文件

- **WHEN** 文件不是支持的备份、结构损坏、实体 ID 重复或包含不支持的 URL 协议
- **THEN** 显示可理解的错误，拒绝导入且不写入任何偏好或资料库数据

#### Scenario: 资料库写入失败

- **WHEN** 存储拒绝导入写入
- **THEN** 不展示成功、不恢复界面偏好，旧资料库保持不变，后续操作仍可重试

### Requirement: 并发修改保护

系统 MUST 通过后台唯一串行写入边界导入，不得以过期预览静默覆盖其他工作台页面的已确认修改。

#### Scenario: 追加期间其他页面修改

- **WHEN** 预览之后另一页面修改资料库，用户随后确认追加
- **THEN** 追加以最新资料库为基础，保留另一页面的修改

#### Scenario: 替换期间其他页面修改

- **WHEN** 替换预览之后资料库发生修改
- **THEN** 拒绝过期替换，要求刷新预览并重新确认

### Requirement: 界面偏好迁移

系统 SHALL 支持恢复备份中的界面偏好，并明确区分资料库导入结果与界面偏好持久化结果。

#### Scenario: 恢复界面偏好

- **WHEN** 用户确认恢复备份的界面偏好且两个存储均写入成功
- **THEN** 主题、明暗、语言与侧栏状态按备份生效，重开页面后保持

#### Scenario: 界面偏好单独写入失败

- **WHEN** 资料库已导入但界面偏好写入失败
- **THEN** 明确提示资料库成功及界面偏好失败，不诱导用户重复追加资料库

### Requirement: 可复用的数据边界

系统 SHALL 将备份协议与导入变换独立于浏览器文件操作及具体存储，继续以异步存储接口承载资料库持久化。

#### Scenario: 使用替代存储验证

- **WHEN** 测试注入内存存储实现并调用同一导入服务
- **THEN** 无需 Chrome API 或 DOM 即可完成相同的校验、追加、替换及失败保护
