# 数据导入导出提案

## 审阅摘要

- 原因：当前数据只能保存在单个浏览器，缺少离线备份和迁移入口。
- 目标：导出包含资料库与界面偏好的备份；支持追加及替换导入，默认追加。
- 边界：本产品 JSON 全量备份；在线存储预留协议与适配边界，本次不接入云服务。
- 验收：离线往返迁移保留内容与顺序；错误输入不写入；并发、容量和部分失败可识别。
- 风险：资料库和界面偏好不具备跨存储事务；需分别报告结果。技术细节见 design，整体待实施批准。

## 已确认变化

用户可从工作台导出所有空间、集合、收藏卡片、保存/恢复偏好以及主题、语言等本机界面偏好。用户可选择向已有资料库追加内容，或替换资料库；默认进入追加模式。

## 范围

### 范围内

备份格式版本、导入校验与预览、两种导入模式、界面偏好迁移、错误反馈、三语界面、针对性测试及迁移说明。

### 范围外

账号、远程服务、自动同步、跨设备冲突算法、第三方书签格式、部分空间导出、备份加密、实时浏览器窗口恢复。

## 能力清单

### 新增能力

- `data-portability`：离线完整备份和安全导入，分离数据协议、导入变换与存储实现，保留在线存储扩展边界。

### 修改能力

无已归档 capability 需要修改；现有首版变更保留历史记录。

## 影响

- 工作台增加数据管理入口；重复网址继续保留，导入不操作实时标签。
- 扩展后台增加专用导入请求；复用本地持久化队列和现有依赖，无新权限或网络请求。
- 更新数据模型服务、消息客户端、界面偏好恢复、预览适配器、文案、测试及 README。
