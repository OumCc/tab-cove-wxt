# 集合按需恢复变更规范

## 审阅摘要

- 新增集合内任意非空子集的打开入口，复用窗口与分组偏好，保留打开整个集合及失败重试行为。
- 验收覆盖顺序、重复网址、取消、空集合和原打开入口；本次选择不写入收藏。

## MODIFIED Requirements

### Requirement: 打开和恢复收藏

系统 SHALL 支持打开整个集合，以及通过独立入口选择本次要打开的收藏条目。两种方式均按集合中的卡片顺序打开，可恢复为普通标签或命名原生标签组；恢复不会移除本地收藏，也不会关闭既有浏览器页面。

#### Scenario: 普通恢复

- **WHEN** 用户选择打开整个集合为普通标签
- **THEN** 其 URL 按收藏顺序打开，重复 URL 仍按收藏中的条目数量打开，本地集合不变。

#### Scenario: 只恢复勾选的收藏

- **WHEN** 用户在非空集合中打开选择弹窗，勾选一个或多个收藏条目并确认
- **THEN** 只在当前窗口打开勾选的条目，遵循其收藏顺序与现有恢复偏好；网址重复的条目可分别勾选，集合内容和顺序不变。

#### Scenario: 选择为空或取消

- **WHEN** 用户在选择弹窗中没有勾选任何条目，或关闭弹窗
- **THEN** 不得发起打开操作；再次进入时默认无勾选，空集合的选择入口不可用。

#### Scenario: 部分恢复失败

- **WHEN** 部分 URL 创建标签失败，或新标签创建后原生分组失败
- **THEN** 已创建标签保留，本地收藏完整保留；明确区分未打开的链接与仅分组失败，不通过重新打开整个集合制造额外重复页。对所选条目的恢复重试不得加入未勾选的条目。
