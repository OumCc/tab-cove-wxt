# 集合按需打开设计

## 审阅摘要

- 用集合头部的清单图标进入选择弹窗，勾选状态限于弹窗。沿用恢复命令避免出现另一套浏览器操作。
- 关键风险是误把未勾选条目交给浏览器；提交时按条目 ID 过滤，并验证打开数量、顺序及分组成员。

## 交互与数据流

1. `Board` 将当前集合和触发按钮交给工作台。弹窗显示可滚动的标题／网址列表，关闭后恢复触发按钮焦点。
2. 弹窗按 `SavedTab.id` 记录勾选状态，提交时用集合顺序生成 `items`；无选项时禁用打开动作。每次询问的普通／分组选择、记住偏好和错误反馈与现有弹窗一致。
3. 工作台共用原有 `BrowserOperation` 协议。打开全部及搜索继续提交全集；按需打开只提交子集。Chrome 组名与组色仍取自集合。

## 验证

使用隔离 UI 预览检查勾选、取消、打开全部、空集合、普通及分组恢复；运行现有自动化测试、类型检查和生产构建。
