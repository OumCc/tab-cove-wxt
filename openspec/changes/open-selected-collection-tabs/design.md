# 集合按需打开设计

## 审阅摘要

- 集合头部的清单按钮进入行内勾选状态，再次点击提交选中条目。选择状态限于当前集合。
- 通过条目 ID 和收藏顺序构造所选子集。预览验收覆盖打开数量、顺序、分组成员及卡片点击。

## 交互与数据流

1. `Board` 展开收起的集合并在原卡片上显示复选框。取消、按 Esc、折叠集合或切换空间清除勾选。取消后焦点回到触发按钮。
2. `Board` 按 `SavedTab.id` 记录勾选，提交时用当前集合的顺序生成 `items`。选择为空时禁用打开动作，选择期间禁用该集合的全量打开与卡片拖拽。偏好为「每次询问」时，原入口确认普通打开，分组是独立的确认动作。
3. 工作台复用 `BrowserOperation`。按需打开提交子集，组名与组色来自集合。命令抛错时保留勾选，部分成功则使用已有报告和重试流程。

## 验证

使用隔离 UI 预览检查第一次点击、行内勾选、第二次点击、取消、打开全部及分组恢复。运行现有自动化测试、类型检查和生产构建。
