# 集合按需打开提案

## 审阅摘要

- 原因：需要恢复少量收藏时，现有集合入口会打开全部标签页。
- 目标：在集合工具栏增加「打开所选标签页」，让用户一次勾选并打开需要的收藏。
- 边界：复用当前窗口、打开偏好和失败处理；无权限、协议或资料库格式变更。
- 验收：未勾选和取消都不打开；确认只打开选中条目；打开全部仍可用。无待确认项。

## 变化

在展开和收起状态下都提供独立入口。弹窗按集合顺序显示标题与网址，默认没有勾选项。「每次询问」时，弹窗同时提供普通打开和分组打开。

## 能力与影响

- 修改 `browser-tab-operations` 的「打开和恢复收藏」能力。
- 工作台工具栏、弹窗及其三语文案受影响；后台恢复服务继续消费原有 `items`。
